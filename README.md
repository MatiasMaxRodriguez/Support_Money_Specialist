# Support Money Specialist

Práctica creando un agente sencillo de asistencia especialista en cotización de moneda extranjera con Kit ADK de manera local, utilizando patrones de instrucciones estructuradas.

Se despliega de manera local con el comando "adk web".

Se utiliza la siguiente estructura:

- [__pyche__/__init__.cpython-312.pyc](https://github.com/MatiasMaxRodriguez/Support_Money_Specialist/blob/main/__pycache__/__init__.cpython-312.pyc)
- [__pyche__/agent.cpython-312.pyc](https://github.com/MatiasMaxRodriguez/Support_Money_Specialist/blob/main/__pycache__/agent.cpython-312.pyc)
- [__init__.py](https://github.com/MatiasMaxRodriguez/Support_Money_Specialist/blob/main/__init__.py)
- [agent.py](https://github.com/MatiasMaxRodriguez/Support_Money_Specialist/blob/main/agent.py)

## Tecnologías utilizadas:

[Agent Development Kit (ADK)](https://adk.dev/)
[Python](https://www.python.org/)
